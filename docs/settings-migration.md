# Settings format migration

Oraxen migrates settings before adding defaults or reading renamed values, even when automatic settings updates are disabled. Custom values move to the paths below. If both paths exist, the explicit new value wins. For sections, Oraxen merges missing values and keeps new values at each leaf. Empty old sections disappear. Unknown settings stay in the file.

`Pack.generation.disable_mcmeta_generation` becomes `pack.generation.mcmeta` with its boolean inverted. All settings bundled on `1.221.0` have a destination. None are intentionally removed in this format change. Previously retired settings still follow the existing removal rules when automatic settings updates are enabled.

Item and mechanic files retain their existing keys. Only settings in `settings.yml` use this format. Pack receive commands accept `opped-player` in settings and retain `opped_player` compatibility in shared action readers.
